## 🌱 Featured Project

### Real-Time Monitoring and Autonomous Smart Irrigation Based on Soil Moisture Profiling

Irrigation shouldn't depend on one surface value. This project builds a **vertical soil profile** so decisions reflect what's happening in the **root zone**.

```
Field → Multi-depth probe → Conditioning/Filtering → Data fusion → KNN / MLP → Irrigation decision
```

- 🧪 **Custom multi-depth probe**: helical capacitive moisture electrodes + temperature sensing at several levels
- 📉 **Signal conditioning** (TLV272-based stage) with temperature-assisted interpretation
- 🌍 **Experiments on black, red and brown soils** (~2 months) with **KNN** and **MLP**
- 🕸️ **Local intelligent network**: nodes cross-check neighbors to flag abnormal or failed sensors, with no cloud dependency
- 🗺️ **Roadmap**: PIC → STM32 nodes + nRF links → Raspberry Pi hub with dashboard, AI and camera (leaf disease / yellowing detection)

> ⚠️ Status: laboratory proof-of-concept (TRL-4 style). Roadmap items are planned, not deployed.
